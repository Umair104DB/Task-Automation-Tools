## Project Overview
A collection of Python utilities demonstrating file organization, email-address extraction from text files and webpage-title retrieval.

This repository is part of a practical CodeAlpha project collection. It demonstrates a focused workflow using Python and related tools.

## Why We Built This Project
Routine file and information-handling tasks can consume time. Python scripts can automate repeatable steps and reduce manual effort with appropriate safeguards.

## Objectives
- Apply Python to a practical problem.
- Build an understandable workflow from input to output.
- Practice reusable programming and data-processing concepts.
- Present results in a clear format.
- Document assumptions and limitations.

## Key Features
- Organize selected files
- Extract email-like strings from text
- Retrieve webpage titles
- Handle common file and request errors

## How It Works
Choose a utility: organize selected image files, extract email-like strings from text, or retrieve and parse a public webpage title.

## Installation
1. Clone the repository:

   ```bash
   git clone https://github.com/Umair104DB/Task-Automation-Tools
   cd Task-Automation-Tools
   ```

2. (Recommended) Create a virtual environment:

   ```bash
   python -m venv .venv
   ```

   Windows PowerShell:

   ```powershell
   .venv\Scripts\Activate.ps1
   ```

   macOS/Linux:

   ```bash
   source .venv/bin/activate
   ```

3. Install project dependencies:

   ```bash
   pip install -r requirements.txt
   ```
